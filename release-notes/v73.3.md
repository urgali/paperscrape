🧹 Under the hood — one way to draw a sprite
- Every sprite in the wallpaper — houses, trees, cars, people, clouds, the sun and moon, birds —
  is now drawn through a single shared piece of code. Until now the same few lines existed six
  times over, once per renderer and once per sprite style, and the copies had quietly drifted
  apart from each other.
- Sprites come in two sizes on disk: some are drawn three times larger than they appear and
  scaled back down for crisper edges, others are stored at their exact on-screen size. Picking
  the wrong one made a sprite come out three times too big or too small with no warning at all.
  That choice is now spelled out wherever a sprite is drawn, instead of being hidden in the name
  of the function doing the drawing.
- One unused drawing function was removed, and a size constant that had been written down twice
  — with a note asking whoever edited it to keep both copies in step by hand — now exists once.

👀 Nothing should look different
- This release is a tidy-up, not a redesign. No artwork, size, position, colour or animation was
  changed on purpose, and the app builds to the same size as the previous beta. If you do spot
  anything that moved, changed size or changed colour, that is a bug — please report it.

🧪 Testing
- 197 automated tests pass, the app builds cleanly with no compiler warnings, and code analysis
  reports three fewer warnings than before and no new ones.
