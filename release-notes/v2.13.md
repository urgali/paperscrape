# v2.13

**Updates install from inside the app, and rain shows up when it is raining.**

**"Install update" now installs.** When an update is found you get three choices: *Remind me
later*, *Check project page*, and *Install update*. Until now the main button opened GitHub and
left you to find the APK yourself — the in-app download that v2.11 added was tucked away in
Advanced & about. Tapping *Install update* starts it straight away: download, checksum, then
Android's own confirmation. *Check project page* still opens the release on GitHub, and now that is
all it claims to do.

**If Android hasn't been told PaperScrape may install apps**, the app no longer just says so — it
takes you to PaperScrape's own "install unknown apps" screen, not the general settings list. Come
back with it turned on and the install carries on where it left off; come back without and it says
exactly what is still missing.

**Rain shows up more reliably.** Open-Meteo reports precipitation in three separate fields, and a
shower over Florence arrives with `rain: 0.0` and the millimetres filed under `showers` — the app
now reads all three, plus snowfall to tell snow from rain. It also trusts a measurement over a
label: if millimetres are falling while the summary code still says "overcast", it rains.

A caveat worth knowing: live weather refreshes at most once an hour, so a shower that starts just
after a refresh can take up to an hour to reach the wallpaper. And the forecast is a model reading
for a grid square, not a look out of your window — a local downpour it did not resolve will not
appear, however the app reads the response.
