# v3.4

**A build-system fix, and nothing else. The app is identical to v3.3 and to v3.2.**

No new features, no behaviour changes, not a line of the wallpaper, the settings or the scene. If
you are already on v3.3 there is nothing here for you.

---

## What this release is

v3.3 got PaperScrape's twenty-one on-device tests as far as starting the emulator. They then did not
run: the build reported `Starting 0 tests`, because installing the app onto the freshly booted
emulator failed.

Android reports "boot completed" some seconds before it is actually able to install a package —
several of its services are still starting up behind that signal. Until v3.3 the gap went unnoticed
because the first thing the test job did was compile the whole project, which took minutes. Once the
emulator setup was fixed and the compile came from cache, the install arrived within seconds of boot
and landed on a half-started system.

The job now builds the app before the emulator starts, and then waits for the emulator to prove it
can actually install and uninstall a package before running anything. On a freshly created Android
17 emulator that takes about sixteen seconds — the exact window the failure was falling into.

That is the entire release. The version number moves because the build configuration changed and
every change gets its own version, not because anything about the app did.
