ℹ️ About the "trees always look like palm trees" report: we traced this
carefully and the underlying code is correct — Christmas (and every
other non-beach theme) is set up to use regular trees, not palms. The
most likely explanation is a theme you saved earlier (via "Manage
Themes") got frozen with palm trees in it at some point, and saved
themes always keep showing exactly what they looked like when saved,
by design. Try opening Manage Themes and resetting the affected theme
back to default — that should clear it up.
