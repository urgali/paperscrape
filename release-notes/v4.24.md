# v4.24

A housekeeping release. **Nothing you can see changes** — no artwork, no setting, no behaviour.
The version number moves so that the project's own documentation, which was rewritten in this
release, ships with a release of its own rather than riding along with the next one that changes
something.

If you are coming from a version older than v4.23, the update dialog shows you the notes for
every release you skipped, and those are where the visible changes are: the trees and the sky
redrawn, the Cars slider made explicit with its own night density, and opening hours for the
shops and towers.
