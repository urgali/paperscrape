# PaperScrape v74

**PaperScrape now draws on the GPU.**

This is the first stable release built on the OpenGL ES renderer. Every previous
version rasterised the whole scene in software, on the phone's main thread —
every gradient, every hill silhouette, every raindrop and all 118 sprites. That
work has moved to the hardware built for it.

## What that means in practice

On a Pixel 9, the CPU cores that carry the wallpaper now sit at roughly **357 MHz
instead of ~2600 MHz**. That is the whole point of this release: much less CPU
work per frame, and with it less battery drain and less warmth, for a wallpaper
that looks exactly the same.

**The scene is unchanged.** Same artwork, same colours, same layout, same
animations, same settings, same themes. Nothing was redesigned and no sprite was
touched — only the way the picture reaches the screen.

## Also in this release

- **Sprites are packed together in memory**, so the whole scene is usually drawn
  in a handful of passes instead of one per object part. Fewer, larger pieces of
  work is what GPUs are fastest at.
- **Lower memory use.** Once a sprite has been handed to the GPU, the app no
  longer keeps a second copy in ordinary memory. That releases up to ~17 MB, and
  a lighter app is one Android is less likely to shut down in the background —
  which for a live wallpaper is what a black home screen looks like.
- Fully transparent things — a raindrop that has faded out, a star mid-twinkle —
  are now skipped instead of drawn invisibly.

## If your device cannot use the GPU

The wallpaper falls back automatically to the old software renderer. There is
nothing to configure and nothing to turn on.

## Upgrading

Your settings, custom themes and colour choices are all preserved.

## Known issue

Dolphins and sailboats do not appear on the lake. This is an older bug, not
something the new renderer caused — it is present in earlier versions too. It is
the first thing being looked at after this release.

If you spot anything else that renders differently from before — a sprite in the wrong
place or at the wrong size, a colour that looks off, a rough edge, or anything
flickering — that is a bug, not a design change. Please report it.
