# v3.0

**Updating from inside the app works again, boats stop sailing through each other, and Live Weather
can find you by cell tower instead of by GPS.**

---

## Updating from inside the app

**"Install update" no longer hangs.** Tapping it used to leave the screen saying "Downloading..."
for ever, with no error and no way out — the check row went grey, so there was nothing left to tap
— and the only way to actually update was to fetch the APK from the Releases page by hand.

The download was never the problem. The screen was cancelling its own download about thirty
milliseconds after starting it, and then had nothing left to move on from. That is fixed, and two
things now make it hard to come back: the download runs somewhere that cannot be cancelled by the
screen redrawing itself, and if a download *is* cancelled for any reason, the screen goes back to
offering the update instead of freezing on a progress bar that has stopped.

**There is a "Verifying" step now.** After the last byte arrives there is still a checksum to
compare and a package to inspect, and the app used to keep saying "Downloading" through all of it.
It now says what it is actually doing.

**Verified against a real release**, not a test fixture: v2.15 updated to v2.16 on a device, through
the app, with the checksum checked and the new version launched.

## The lake

**Two boats can no longer sail on top of each other.** With several boats out, two of them shared a
line across the water and, moving at different speeds, slid straight through one another — one hull
drawn over the other with no sense of which was nearer.

Two things were wrong and both are fixed. Every boat and every dolphin now gets its own line, so
nothing shares one; and the water is painted from the far side to the near side, so when two boats
do pass, the nearer one is in front. Overlapping now looks like one boat passing another, which is
what it is.

Nothing else about the lake changed: same boats, same speeds, same paths, same look.

## Live Weather: GPS, Network / Cell, or Custom

The location setting used to be **Off / Phone / Custom**, and "Phone" was vague on purpose because
it did not really know either — it asked for a network position and quietly fell back to the GPS
receiver if that was unavailable. Choosing the cheap option could power up GNSS without saying so.

It is now **Off / GPS / Network / Custom**, and each means exactly what it says:

- **GPS** — the receiver, for a precise position. Asks for precise location permission.
- **Network / Cell** — cell towers and Wi-Fi only, accurate to roughly your town, which is all a
  weather forecast needs. Asks only for *approximate* location permission, and **never starts the
  GPS receiver**, even if the network position is unavailable.
- **Custom** — a place you pick. No permission, no battery, unchanged.

**And it stopped following you around.** Both device modes used to keep a location subscription
running for as long as the wallpaper was alive, waking the positioning stack every ten minutes
whether or not anything needed it. Now a position is asked for once, when the weather is about to be
refreshed — at most once an hour — and if the system already knows where the device is, that answer
is used and nothing is woken at all.

**If your position cannot be found, the wallpaper keeps the last one it knew.** No signal, no
network position, permission refused: the scene carries on with the weather for where you last were,
rather than jumping somewhere else or going blank. If there has never been a position, it says so
and falls back to the theme's own weather.

## Testing

**Thirteen reference frames of the scene are now checked automatically.** Day, dusk, night,
overcast, rain, snow, thunderstorm, three lakes and three themes are each rendered and compared
against a stored image, so a change that quietly moves something in the scene fails a test instead
of shipping. They are rendered through the same drawing code the app uses, not a copy of it.

Nothing about how the app looks was changed to make these possible.

## Under the hood

PaperScrape is now a fully standalone project. Earlier versions were built partly by comparison with
another wallpaper app, and its fingerprints were all over the source comments — decisions justified
by "that is how the other one does it" rather than by a reason you could check. Those are gone,
rewritten to say what the code actually does and why. The changelog and the old release notes still
describe the history as it happened; rewriting those would be pretending it did not.

## Also

The outlined buttons have looked a little different since v2.16 — grey-brown rather than orange.
That is Material Design's current default for that kind of button, not a bug, and it stays.
