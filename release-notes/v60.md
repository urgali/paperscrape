🆕 New
- 🍂 Fall Colors: turn on autumn-toned trees with leaves drifting down, from the Seasonal
  Decorations menu — works on any theme, any time.
- 🎄 Winter/Christmas Colors: turn on snow-dusted trees with blinking Christmas lights, same menu
  — mutually exclusive with Fall Colors.
- 📍 Custom location: enter a location manually (latitude/longitude, with an optional name) for
  precise sunrise/sunset — mutually exclusive with using your phone's real location.
- ☔ Live Weather: real current conditions (rain, snow, thunderstorms, cloud cover) now replace
  each theme's manual weather settings automatically, refreshed once an hour. Needs phone location
  or a custom location turned on first so it knows where to check.

🎨 Improved
- Umbrellas no longer look like they're floating above the sand — the canopy was drifting away
  from the pole slightly on every sway; it now stays properly attached.
- Houses, buildings, and trees are now placed with clearer front-and-back depth on the hillside
  instead of clustering together.
