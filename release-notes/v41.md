✨ New
- **Rain and Snow** — a new "🌧️ Precipitation" screen under Scene
  Objects. Turn it on, pick Rain or Snow, set how heavy it falls, and
  customize the colors for each (they're remembered separately, so
  switching between Rain and Snow doesn't reset your colors).
- **Thunderstorms** — while Rain is selected, flip on "Thunderstorm" for
  occasional lightning flashes across the sky.
- **Rainbows** — a new "🌈 Rainbow" screen. Show/hide it and control how
  vivid it looks. It's independent from the rain settings, so you can
  add a rainbow to any theme you like, sunny or not. It fades away at
  night, just like a real rainbow would.
- Winter, Christmas and Tundra start with Snow pre-selected (still off
  by default, like everything else here) so if you turn precipitation on
  for those themes, it's already snowing instead of raining.
