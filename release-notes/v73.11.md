# PaperScrape v73.11

The wallpaper now draws with the GPU.

Until this release every frame was rasterised in software on the phone's main
thread — every gradient, every hill silhouette, every raindrop and all 118
sprites. This release replaces that with an OpenGL ES renderer running on its own
thread, which is what the scene should have been drawn with all along.

**The scene itself is unchanged.** Same artwork, same colours, same layout, same
animations, same settings. Nothing has been redesigned, no sprite has been
touched, and every position is calculated exactly as before. Only the way those
pixels reach the screen has changed.

## What you should notice

- **Lower CPU use**, and with it less battery drain and less warmth. The work of
  filling the screen has moved to the hardware built for it.
- **The scene still runs at its usual gentle pace.** The renderer is deliberately
  held to the same frame rate as before rather than being allowed to run as fast
  as the display can refresh, which would have burned more power for motion this
  slow.

## What you should not notice

Nothing about how the wallpaper looks. If you spot anything that renders
differently from before — a sprite in the wrong place or at the wrong size, a
colour that looks off, an edge that looks rougher, or anything flickering — that
is a bug in this release, not a design change. Please report it.

## If your device cannot use the GPU

The wallpaper falls back automatically to the previous software renderer. There
is nothing to configure and nothing to turn on.

## Notes

This is a development build for testing. The Android version is unchanged, so it
installs over your current build and keeps all your settings and custom themes.
