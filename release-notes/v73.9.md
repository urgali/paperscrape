## Lighter artwork

The wallpaper looks exactly the same as before. Every scene, sprite, colour,
animation and setting is unchanged — this release is about what the app holds in
memory while drawing them.

Each piece of artwork was stored inside an image much larger than the drawing it
contained, with the empty space around it kept in memory and redrawn every frame
for no visible result. More than half of everything the wallpaper loaded was that
empty space.

The empty margins have now been removed and the drawing code adjusted by exactly
the same amount, so every sprite still appears in precisely the same place at
precisely the same size. The artwork the wallpaper keeps in memory dropped from
about 33 MB to about 17 MB.

A few sprites were deliberately left alone, either because trimming them would
have shifted how they line up with the artwork around them, or because doing it
properly needs a decision about the drawing itself rather than about its margins.

The result should be a wallpaper that is easier on memory, particularly on
smaller devices and when several scenes are visible at once.
