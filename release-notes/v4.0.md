# v4.0

**PaperScrape now targets Android 17, and the location settings tell you where you are in words.**

Two changes, and deliberately nothing else.

---

## Built for Android 17

PaperScrape now *targets* Android 17 rather than Android 16. In practice this means the app opts
into Android 17's own rules for how apps behave instead of asking the system to keep treating it as
an older app.

There is nothing to do and nothing to notice. Every Android 17 change was checked against what this
app actually does, and none of them needed a fix: PaperScrape has no notifications, no background
services, no local-network access, no native code and no reflection, and it never starts anything
from the background. The wallpaper, the weather, the location modes and the updater all behave
exactly as they did in v3.9.

The one part of this that genuinely changes is invisible: Android 17 enforces stricter checks on
secure connections. Every address the app talks to — the three weather services, the city lookup
and the GitHub release check — was exercised on a device running the new build, and all five
connect normally.

## The location settings now name the place

Choosing **GPS** or **Network** used to show either a place name or a pair of coordinates,
depending on whether the name lookup happened to succeed — so the coordinates disappeared the
moment the name arrived, and there was no way to check them.

Now you get both:

```
Milano, Italia
45.46, 9.19 - Resolved from the GPS receiver
```

**The coordinates are never lost.** Before the name arrives, and if it never arrives at all, the
coordinates are what you see — a name lookup that fails costs you the name and nothing else. It is
not a location error and is no longer able to look like one.

The name comes from Android's own address lookup, so it appears in your device's language, and it
is asked for sparingly: once per place, not once per position update. Moving across town gets you a
new name; a fix drifting a few metres on your desk does not.

**Custom locations are unchanged.** A place you picked yourself already has the name you gave it,
so nothing new is looked up there.

---

## Everything else is the same

The scene, the artwork, the twelve themes, the weather providers and the updater are untouched.
Open-Meteo is still the default weather service and still needs no account.
