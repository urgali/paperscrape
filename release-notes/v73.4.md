Performance work on how scene objects are drawn. Nothing about the wallpaper
should look any different — this release is about how much work the phone does
to produce the same picture.

**What changed**

- Houses, buildings, trees, parasols and seasonal decorations are drawn in
  repeating copies so the scene never shows a seam as it scrolls. Until now
  three copies of every object were prepared each frame and two were usually
  thrown away. The renderer now works out which copies can actually be on
  screen and prepares only those.
- Two sources of per-frame memory churn were removed from the drawing code:
  one in how an object's position was passed around, one in how the road strip
  measured its lanes. Less garbage collection means fewer chances of a stutter.

**What did not change**

Object sizes, positions, colours, depth ordering, animation and scroll
behaviour are all untouched. The copies that end up painted are the same ones,
at the same coordinates, down to the last decimal place — this is checked
automatically against the previous behaviour across the full range of screen
sizes and scroll positions.

No new settings, and nothing to do after updating.
