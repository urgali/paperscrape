# v3.3

**A build-system fix, and nothing else. The app is identical to v3.2.**

Nothing you can see has changed: no new features, no fixes to anything the app does, not a single
line of the wallpaper, the settings or the scene. If you are already on v3.2 there is no reason to
hurry.

---

## What this release is

v3.2 added a job that runs PaperScrape's twenty-one on-device tests automatically on every change —
the fourteen reference images of the scene, three of the graphics backend, and the settings-file
recovery suite. Its first real run never got as far as starting the emulator: it asked the Android
SDK for a package called `platforms;android-37`, and no such package exists.

Android's platform packages began carrying their minor version from 36.1 onward, so what the SDK
actually publishes is `android-36`, `android-36.1`, `android-37.0`, `android-37.1` — and no bare
`android-37`. The job now asks for the name that exists.

That is the entire release. The version number moves because the build configuration changed and
every change gets its own version, not because anything about the app did.
