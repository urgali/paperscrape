# v3.9

**A small corrective release. Two things, and nothing else.**

Nothing about how the wallpaper looks has changed, and no setting you have chosen is touched.

---

## OpenWeather: "could not be reached" was the wrong thing to say

If you picked **OpenWeather** as your weather service and entered a key, the settings screen could
tell you:

> OpenWeather could not be reached.

That message sent people to check their connection, and their connection was fine. What had actually
happened is that OpenWeather answered immediately and **refused the key** — and the app had no way
of saying so, because it reported every kind of failure with the same sentence.

This matters far more for OpenWeather than for the other two services, and for a reason that is
easy to miss: **OpenWeather does not accept a brand-new key straight away.** Its own help pages say
a newly created free key takes a couple of hours to start working. So the most likely person to see
that message was someone who had just signed up, pasted a key that was completely correct, and been
told their internet was broken. Open-Meteo needs no key at all, and a WeatherAPI.com key works the
moment it is issued — which is why only OpenWeather ever showed this.

The app now tells you what really happened:

> OpenWeather rejected this API key. Check that it is correct — and if you have only just created
> it, a new key can take a couple of hours to become active, which looks exactly like a wrong one.

Genuine connection problems still say "could not be reached", because for those it is true.

**Nothing about how the weather itself is fetched has changed.** The service, the web address, the
readings and the way rain and snow are interpreted are all exactly as they were in v3.8 — they were
checked against the live service with a real key during this release and were correct. Open-Meteo
remains the default for anyone who has not chosen otherwise.

## A build warning removed

The project's build file used a piece of the Android build system that has since been marked
obsolete. It has been replaced with the current equivalent. The build produces exactly the same
result — this is housekeeping, with no effect on the app.

---

## Everything else is unchanged

`targetSdk` is unchanged in this release. Open-Meteo is still the default weather service, the
traffic and winter artwork are untouched, and every one of the previous release's checks still
passes.
