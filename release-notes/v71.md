☁️ Look and feel — clouds redrawn
- Clouds have been redrawn from scratch in the same "paper cutout" style as everything else so
  far, with soft baked-in shading for a bit of volume.
- Clouds should now also fill the sky properly at high density — there can be noticeably more of
  them on screen at once without any slowdown, since the new clouds are much cheaper to draw
  than the old ones were.

🌈 Look and feel — rainbow gets a small touch-up
- Each band of the rainbow now has a subtle brighter inner edge, giving it a bit more of a
  rounded, "folded paper" look instead of flat stripes.
- Unlike clouds, the rainbow wasn't converted to the new image-based style this round — its size
  needs to stretch to fit any screen width, which doesn't work well with the fixed-size image
  approach used elsewhere. That'll get its own proper update later.

⚙️ Under the hood
- This is "batch 4, part 2" (clouds & rainbow) of the larger aesthetic overhaul. Still remaining:
  birds, sun/moon, stars, Santa's sleigh, and the seasonal decorations (snowman, gift, penguin,
  Easter egg/bunny, balloon, pumpkin, beach umbrella).
- Same as previous updates: couldn't run a full local test build this round (no Android build
  tools in the tool environment) — please treat this as needing a proper test more than usual.
