# v2.16

**A maintenance release. The wallpaper looks and behaves exactly as it did in v2.15 — what changed
is everything underneath it.**

**Why this release exists.** PaperScrape was still being built with the Android libraries it was
written against in late 2024. Nothing was broken by that, but every month it stays there is a month
of accumulated distance from the tools the platform actually ships, and the gap is cheapest to
close before something needs a newer API rather than after. So the whole build stack moved to the
current stable line in one deliberate pass: Gradle 9.5.0 → 9.7.1, the Android Gradle Plugin 9.3.0 →
9.3.1, Kotlin 2.2.10 → 2.2.21, and the AndroidX, Compose, DataStore and Coroutines libraries onto
their newest stable versions.

**PaperScrape now compiles against Android 17.** That is a build-time setting: it says which version
of Android the code is checked against, not which one it behaves like. The behaviour setting was
deliberately left where it was, so this release cannot change how the app runs on your phone. That
is a separate step, and it will get its own testing before it happens.

**Not a single line of the app's own code changed.** No rendering, no weather logic, no settings, no
new features. The 688 automated tests all pass, exactly as they did before, and the app was run on
Android 17 and compared against v2.15 screen by screen: the main settings screen came out
pixel-for-pixel identical, and everywhere else the only differences are single pixels along the
edges of letters and sprites, which is the newer graphics stack drawing the same thing very
slightly more smoothly.

**One thing does look different, and it is not ours.** The outlined buttons — "Reset this theme's
scene to defaults", "Try again", and the buttons in the update dialog — are now grey-brown with a
paler outline instead of orange. Google changed what an outlined button looks like by default in
this version of Material Design, and PaperScrape follows Material Design rather than pinning an
older look in place. Everything else — filled buttons, dialog buttons, switches, sliders, text — is
unchanged.

**Nothing you had set is lost.** Themes, customisations, saved themes, location and Live Weather
settings all survive the update; the storage layer was upgraded too and was checked specifically for
this.

## Known problem: updating from inside the app

**The in-app updater can get stuck on "Downloading..." and never finish.** If that happens, the
download simply never completes and the dialog stays where it is.

**What to do meanwhile:** download the APK yourself from the
[Releases page](https://github.com/urgali/paperscrape/releases) and open it — it installs over your
current version and keeps all your settings.

This was reported against v2.15 and it is **not fixed in v2.16**. It has not been investigated yet,
so nothing is claimed here about what causes it. Diagnosing and fixing it is the next piece of work,
and the fix will be reproduced and verified against a real release before it ships.

*Checking* for updates works normally — it is only the download step that can hang.
