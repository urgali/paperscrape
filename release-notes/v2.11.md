# v2.11

**Update from inside the app, and one preview system instead of two.**

**Updates no longer send you to GitHub.** Advanced & about → Updates now does the whole thing:
check, download, verify, install. When there is a new release you get *Update available* and a
**Download and install** button; the download shows its progress, and when it finishes Android asks
you to confirm the install, as it does for any app package.

**Every download is checked before it is offered to the installer.** The release publishes a
SHA-256 alongside the APK, and the app compares the file it received against it. If they do not
match, the file is deleted rather than installed. If a release has no checksum at all, the in-app
install is not offered — you are pointed at the release page instead, because an app package that
nothing has verified is not something to install for you. The downloaded file is also checked to be
PaperScrape, and to be newer than what you have, before anything happens.

**Nothing downloads or installs on its own.** *Check for updates automatically* still only tells
you a release exists; the download is a tap and the install is another, plus Android's own
confirmation. The first time, Android will ask you to allow installs from PaperScrape — the app
explains that and takes you to the right settings screen.

**The preview in World & scene is the same preview as in the theme gallery.** It used to be a
narrow strip showing three sample objects, each enlarged by a different amount so a house, a tree
and a tower would all fit — useful for checking a colour, and nothing like the mini scenes the
gallery had gained. It is now the same scene, at the same shape and the same scale, showing your
current theme with your current settings: sky, ground, buildings, trees, the road, people, cars and
whatever decorations are on. The day/night switch stays, because half of what you edit below it are
night colours.

Nothing else changed: the wallpaper, the themes, the gallery previews, Live Weather, the city
search and the rest of the settings are all as they were in v2.10.
