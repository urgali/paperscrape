# v73.5

**Nothing in the wallpaper changes in this build.** No sprite, colour, size,
position or animation is different from v73.4, and no app code was modified at
all. If you install this over v73.4 you should not be able to tell them apart —
if you can, that is a bug worth reporting.

## What this release is for

Until now, every sprite in PaperScrape was its own source. The scripts that drew
them were never saved, so a sprite could not be resized, recoloured or corrected
without editing it pixel by pixel. That is the single biggest obstacle to
improving how the scene looks.

This release builds the missing half: a source pipeline. Sprites can now be
described as vector drawings and turned into the images the app loads, the same
way every time, on any machine.

## Where it got to

24 of the 118 sprites now have a real source — the plain and rounded rectangles
that make up walls, windows, doors, trims and tower sections. Their shapes were
recovered by measuring the existing images rather than by redrawing them by eye,
and 11 come back out pixel for pixel identical to what ships today.

The other 94 do not have a source yet, and the release says so rather than
pretending otherwise. Anything hand-drawn — the people, Santa's sleigh, the
clouds, the shop signs — cannot be recovered by measurement. Those will be
redrawn properly in a later release, with previews to look at before anything
changes.

A small bonus discovery: every corner radius measured out of the old sprites
landed exactly on the grid the project is supposed to be drawn on. Whoever wrote
the lost scripts was following the rules.

## Known and unchanged

Sprites still carry a lot of empty transparent space, some are still duplicates
of each other, and the summer and winter character heads are still the same
image. Those are next, and each needs the pipeline that landed here first.
