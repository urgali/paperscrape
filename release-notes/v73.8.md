## Asset manifest

Nothing in this release changes the wallpaper. No sprite, colour, animation or
setting is different, and the app itself is byte-for-byte the same as v73.7 —
every change is in the developer tooling that describes the artwork.

That tooling now records, for each of the 118 sprites the wallpaper draws, where
its visible content actually sits inside its image and — where it can be
established — the point the drawing code positions it by. Previously an image
carried no record of either, so the only way to know how a sprite was meant to be
placed was to read the code that placed it. When those two quietly disagreed, as
happened with the sun and the stars in v73.7, nothing noticed.

The tooling now checks the description against the drawing code and reports any
disagreement. Where it cannot establish something with certainty, it says so
rather than guessing: 17 of the 118 sprites have a confirmed anchor point, and
the remaining 101 are recorded as undetermined with the reason stated.

This is groundwork. It does not fix any sizing or alignment issue on its own; it
makes the next round of asset work verifiable instead of hand-tuned.
